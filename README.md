# SkillShikshya Student Resources

Welcome to the **Python Foundation Repository** 🎓

This repository contains your **daily class slides, notes, code examples, assignments, and additional learning resources**.

## 📚 How to Use

### Option 1: Download ZIP

1. Open this GitHub repository.
2. Click **Code** → **Download ZIP**.
3. Extract the ZIP file on your computer.
4. Open the folder and access the required class materials.

> **Note:** If you download the ZIP, you will need to download it again whenever new materials are added.

### Option 2: Clone the Repository

If Git is installed on your computer:

```bash
git clone <repository-url>
```

Move into the repository:

```bash
cd <repository-name>
```

### 🔄 Get New Class Materials

New slides and resources will be added regularly.

After cloning the repository, run:

```bash
git pull origin main
```

Run this command whenever you want to get the **latest class materials and updates**.

You can also simply use:

```bash
git pull
```
