⚠️ The #1 Beginner Trap — input() Gives You Text

THE PROBLEM
age = input("Enter your age: ")
# User types: 15
# BUT age = "15"  ← it's a STRING, not a number!

print(age + 10)
# TypeError: can't add string and int

print(age + "10")
# "1510"  ← strings just join together!
THE FIX — WRAP WITH int()
# Wrap input() with int() to convert to number
age = int(input("Enter your age: "))
# Now age = 15  ← a real integer

print(age + 10)    # 25 ✅

# Use float() for decimal inputs
price = float(input("Price: "))
print(price * 1.13)  # price with tax ✅
🧠 Rule: whenever you need to do maths with user input, wrap it with int() or float().

Shorthand Operators ⚡

These are shortcuts for updating a variable using itself. You'll see them everywhere — especially in loops.

# Long way
score = score + 10
score = score - 5
score = score * 2

# Short way — exactly the same result
score += 10   # add 10 to score
score -= 5    # subtract 5
score *= 2    # multiply by 2
# Real example — a simple counter
count = 0
count += 1   # count = 1
count += 1   # count = 2
count += 1   # count = 3
print(count)  # 3

# Running total
total = 0
total += 120  # total = 120
total += 350  # total = 470
print(f"Total: Rs. {total}")
💡 += is by far the most used shorthand. You'll use it constantly in loops next week!

Strings
Type: str — working with text

Strings — Text in Python

A string is any text inside quote marks — letters, words, sentences, emoji, anything!

# Single or double quotes — both work
greeting = "Hello, World!"
city     = 'Kathmandu'
mood     = "Python is 🔥"

# + joins strings, * repeats them
print("Hello, " + "world!")   # Hello, world!
print("⭐" * 15)               # ⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐⭐
⚠️ A number in quotes is still a string: "42" ≠ 42 — one is text, one is a number!

String Methods — Built-in Superpowers 🔧

Case & length

word = "python"

word.upper()    # "PYTHON"
word.lower()    # "python"
word.title()    # "Python"
len(word)       # 6

name = input("Name: ").strip()
# .strip() removes accidental spaces

Checking & replacing

sentence = "Hello World"

sentence.startswith("Hello")  # True
sentence.endswith("World")    # True
sentence.replace("World", "Python")
# "Hello Python"

"hello" in sentence  # False (case-sensitive!)
"Hello" in sentence  # True
🚀 Methods are called with a dot: variable.method() — the dot is key!

String Indexing — Picking Individual Letters 🔤

Every character in a string has a position number called an index. Counting starts at 0, not 1.

word = "Python"
P
0
y
1
t
2
h
3
o
4
n
5
word = "Python"

word[0]    # "P"  ← first character
word[1]    # "y"
word[-1]   # "n"  ← last character
word[-2]   # "o"  ← second to last

# Slicing — grab a chunk
word[0:3]  # "Pyt"  (0, 1, 2 — stop before 3)
word[2:]   # "thon" (2 to end)
🧠 Indexing starts at 0. The last item is always [-1]. Remember this — it's the same for lists too!

type() — What Kind of Data Is This? 🔍

type() tells you exactly what kind of data you're dealing with. Very useful when debugging.

print(type("Hello"))   # <class 'str'>
print(type(42))        # <class 'int'>
print(type(3.14))      # <class 'float'>
print(type(True))      # <class 'bool'>

age = input("Age: ")
print(type(age))       # <class 'str'> ← always!

Type Conversion

int("100")      # str → int   : 100
float("3.14")  # str → float : 3.14
str(42)         # int → str   : "42"

# The classic fix pattern:
age = int(input("Your age: "))
print(f"Next year: {age + 1}")
🔑 Use type() whenever you're confused about why your code isn't working. It's your first debugging tool!

Booleans
True or False — that's it

Booleans — Two Values Only

A boolean can only be True or False. They power every decision your program makes (more on that tomorrow!).

# Direct assignment
is_raining    = False
has_homework  = True

# Comparison operators produce booleans
print(10 == 10)   # True  — equal to
print(10 != 5)    # True  — not equal
print(10 >  20)   # False — greater than
print(10 <= 10)   # True  — less or equal
🧠 == checks if two things are equal. = stores a value. Completely different — don't mix them up!

Common Mistakes Today ⚠️

❌ Forgetting int() with input()
age = input("Age: ")
print(age + 10) ← TypeError
age = int(input("Age: "))
print(age + 10) ← ✅ works
❌ Mixing strings and numbers with +
"Age: " + 15 ← TypeError
f"Age: {15}" ← ✅ use f-string
❌ Using = instead of == to compare
if score = 100: ← SyntaxError
if score == 100: ← ✅ correct
