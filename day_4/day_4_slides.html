What are Collections? 📚

A normal variable stores one value. A collection stores many values in one labelled box.

📝
List
Ordered items you can change
["a", "b", "c"]
📦
Tuple
Ordered items that stay fixed
(10, 20)
🗝️
Dictionary
Labelled values by key name
{"name": "Aisha"}
🧠 Think of collections as backpacks: you carry many things using one name.

📝
Lists
Ordered & mutable

Storing Many Values in a List

Lists use square brackets and can hold any values. You can read, change, add, remove, and search items.

fruits = ["apple", "banana", "cherry", "banana"]

# Access and change (mutable)
print(fruits[0])                  # apple
fruits[1] = "mango"

# Add and remove
fruits.append("orange")           # add to end
fruits.insert(1, "kiwi")          # insert at index
fruits.remove("cherry")           # by value
last = fruits.pop()               # remove last

# Info about the list
print(len(fruits))                # how many
print(fruits.index("apple"))      # first position
print(fruits.count("banana"))     # occurrences

# Sort, slice, and check
fruits.sort()                     # A to Z
fruits.reverse()                  # flip order
print(fruits[0:2])                # first two items
print("mango" in fruits)          # True / False
✨ Lists use [], start counting at 0, and are mutable — you can change them!

Tuples — Fixed Collections 📦

Tuples look like lists but use parentheses. Once created, they cannot be changed — they are immutable.

point = (10, 20, 10)

# Access by index
print(point[0])         # 10

# This would crash (immutable):
# point[0] = 99

# Tuple methods
print(point.index(20))   # position of 20
print(point.count(10))   # how many 10s
print(len(point))        # 3
⚠️ Tuples are great for values that should never change, like coordinates or RGB colours.

List vs Tuple

List []
Can add, remove, change items. Use for collections that grow.
Tuple ()
Cannot change after creation. Use for fixed records.
Common uses: screen coordinates (x, y), colours (255, 0, 0), days of the week.

Dictionaries
Key-value pairs

Accessing Data by Name

Dictionaries store values with keys instead of positions. Think of a real dictionary: word → definition.

student = {
    "name": "Aisha",
    "age": 14,
    "grade": "A"
}

# Access by key and .get()
print(student["name"])              # Aisha
print(student.get("school", "N/A"))  # safe access with default

# Change and add
student["age"] = 15                 # change value
student["school"] = "Central High"  # add new key

# Update multiple at once
student.update({"city": "Dubai", "age": 15})

# Remove and return
old_grade = student.pop("grade")

# View all parts
print(student.keys())               # all keys
print(student.values())             # all values
print(student.items())              # key-value pairs

# Copy and clear
backup = student.copy()
student.clear()                     # empties the dict

# Check key exists
print("name" in student)            # True / False
🔑 Dictionaries use {} with key: value pairs. Keys are labels, not numbers!

What are Conditions? 🔀

Every day you make decisions based on conditions:

Python uses conditions the same way — a question with a True or False answer determines what code runs.

🧠 Conditions turn data into decisions. This is where programs start to feel intelligent!

if / else
The foundation

The if Statement — Two Paths

The if block runs only when the condition is True. The else block runs when it's False.

# Anatomy of an if/else
if condition:
    # runs when condition is TRUE
    print("Yes!")
else:
    # runs when condition is FALSE
    print("No!")

# Real example
age = 16
if age >= 18:
    print("You can vote! 🗳️")
else:
    print("Too young to vote.")
⚠️ The colon : after if and else is required. The body must be indented 4 spaces!

if / else in Action 💡

EXAMPLE 1 — PASSWORD CHECKER
password = input("Enter password: ")

if password == "python123":
    print("✅ Access granted!")
else:
    print("❌ Wrong password!")
💡 == compares. = assigns. Don't mix them up!
EXAMPLE 2 — INDENTATION RULES
score = 75

if score >= 60:
    print("You passed! 🎉")   # inside if
    print("Well done!")        # still inside if
else:
    print("You failed. 😔")    # inside else

print("Exam is over.")       # NOT indented — always runs
⚠️ Python uses indentation (4 spaces) to know what is "inside" a block. Wrong indentation = error!

elif — More Than Two Paths

elif stands for "else if". It adds more branches — Python checks them one at a time from top to bottom and runs the FIRST one that is True.

score = 82

if   score >= 90:  print("A")   # 90–100
elif score >= 80:  print("B")   # 80–89  ← runs for 82
elif score >= 70:  print("C")   # 70–79
elif score >= 60:  print("D")   # 60–69
else:              print("F")   # below 60
🔑 You can have as many elif branches as you need. The else is optional — it catches everything that didn't match.

elif in Action 🚦

Traffic Light

light = input("Colour? ").lower()

if light == "red":
    print("STOP! 🔴")
elif light == "yellow":
    print("Get ready... 🟡")
elif light == "green":
    print("GO! 🟢")
else:
    print("Unknown colour!")
💡 .lower() converts input so "Red", "RED", "red" all match!

Using in to check multiple values

month = int(input("Month (1–12): "))

if month in [12, 1, 2]:
    print("Winter ❄️")
elif month in [3, 4, 5]:
    print("Spring 🌸")
elif month in [6, 7, 8]:
    print("Summer ☀️")
else:
    print("Autumn 🍂")
✨ value in [a, b, c] checks multiple values in one line!

and · or · not — In Depth 🔬

# AND — both must be True
is_member  = True
has_points = False

if is_member and has_points:
    print("Free gift! 🎁")      # won't run

# OR — at least one True
if is_member or has_points:
    print("You get a discount!") # runs!

# NOT — flips the boolean
is_raining = False
if not is_raining:
    print("Great day for a walk! ☀️")

Truthy & Falsy Values 💡

Python doesn't need an actual True or False — every value has a built-in truthiness.

😴 FALSY — acts like False
bool(0)        # False — zero
bool("")        # False — empty string
bool([])        # False — empty list
bool(None)      # False — no value
✅ TRUTHY — acts like True
bool(1)        # True — any non-zero
bool("hello")  # True — non-empty string
bool([1,2])    # True — non-empty list
bool(True)     # True — obviously!
name = input("Your name: ")
if name:   # True if user typed something, False if just Enter
    print(f"Hello, {name}!")

Putting It All Together — Grade Calculator 🎓

name  = input("Student name: ")
score = int(input("Score (0–100): "))

if score < 0 or score > 100:
    print("Invalid score!")
elif score >= 90:
    print(f"{name}: A — Distinction! 🌟")
elif score >= 80:
    print(f"{name}: B — Well done! 👍")
elif score >= 70:
    print(f"{name}: C — Good effort.")
elif score >= 60:
    print(f"{name}: D — Passing.")
else:
    print(f"{name}: F — Study harder! 📚")

Concepts used in this one program

  • 📥int(input()) — read and convert user input
  • 🔗or — validate the score is in range
  • 🎛️elif chain — grade bands from A to F
  • 🔤f-string — personalised output with the name
  • 🏆else — catches anything below 60
✅ This is a complete, working program — and you understand every single line of it!
