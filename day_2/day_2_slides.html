Python
What it is & why we use it

What is Python? (60-second version)

Python is a programming language — a way of giving instructions to a computer that both you and the computer can understand.

  • 📖Reads like English — easier to learn than most languages
  • 🌍Used everywhere — AI, websites, data science, automation
  • 🆓Free and open source — anyone can use it
  • ⚡Instant feedback — write a line, run it, see the result
🧠 Think of it like this: computers only understand 1s and 0s. Python is the translator in the middle — you write something close to English, Python turns it into something the computer can run.

print()
Your first Python command

print() — Show Things on Screen

print() is how Python shows something to you. Whatever you put inside the brackets gets displayed on screen.

print("Hello, world!")
print("My name is Alice.")
print(42)
print("⭐" * 10)   # prints ⭐ ten times
⚠️ Text must always be inside quote marks — either "double" or 'single'. Numbers do not need quotes.
5 / 14

print() in Action 💡

BASIC EXAMPLES
print("Good morning!")
print('Python is fun')   # single quotes ok too
print(100)
print(3.14)
print("Line 1")
print("Line 2")         # each print = new line
print()               # empty print = blank line
COMMON MISTAKES
❌ Missing quotes
print(Hello) ← NameError!
❌ Capital P
Print("Hello") ← Python is case-sensitive!
✅ Correct
print("Hello") ← lowercase, quotes closed
🧠 Error messages tell you exactly where and why something broke. Always read them!

Variables
Store and reuse values

Variables — Labelled Boxes

A variable is a labelled box where you store a value. Give the box a name, put something in, and use the name whenever you need that value.

name  = "Alice"      # a box called "name" holding "Alice"
age   = 15           # a box called "age" holding 15
city  = "Kathmandu"

print(name)   # Alice
print(age)    # 15

age = 16      # update the box anytime
print(age)    # 16
🔑 = means "store this value" — it is NOT the equals sign from maths!
7 / 14

Variable Naming Rules 📝

✅ Good names

  • first_name = "Bob" — underscore for spaces
  • score1 = 100 — numbers OK (not at start)
  • is_happy = True — descriptive and clear
  • total_price = 250 — lowercase_with_underscores

❌ Never do this

  • 1score = 100 — cannot start with a number
  • my score = 100 — no spaces in names
  • my-score = 100 — dash means subtraction!
  • @name = "Bob" — no special characters
💡 Good names describe what is inside the box. student_age beats x every time!

input()
Ask the user to type something

input() — Talk to Your User

input() pauses your program and waits for the user to type something. Whatever they type is given back to you as text.

name = input("What is your name? ")
print("Nice to meet you, " + name)

city = input("Where are you from? ")
print("Cool! " + city + " is a great place.")
📌 The message inside input("...") is a prompt. Always end it with a space so it looks clean.
⚠️ input() always gives you text (a string) — even if the user types a number!

f-strings
The clean way to mix text and variables

f-strings — Mix Text and Variables Neatly

Put an f before the quote and use {curly braces} to drop variables right into your text.

name = "Alice"
age  = 15

# Old way — messy with lots of +
print("Hello, " + name + ". You are " + str(age) + " years old.")

# f-string — clean ✨
print(f"Hello, {name}. You are {age} years old.")

# You can even do maths inside!
print(f"Next year you will be {age + 1}.")
🚀 Always use f-strings when mixing variables with text. Much cleaner than lots of + signs!

Putting It All Together 🎯

A COMPLETE PROGRAM
# greeting_card.py
name    = input("Your name: ")
city    = input("Your city: ")
feeling = input("How are you feeling? ")

print()
print("================================")
print(f"  Hello, {name}!")
print(f"  From {city}, feeling {feeling}.")
print("  Welcome to Python! 🐍")
print("================================")
WHAT EACH PART DOES
# comment — Python ignores this, it's just a note for you
input("...") → pauses → user types → stored in variable
print() with nothing → prints a blank line
f"... {name} ..." → inserts variable into text
✅ This is a real, complete Python program. You built it today.

Comments — Notes in Your Code 💬

A comment starts with #. Python completely ignores everything after it on that line.

Comments are for you — to explain what your code does, leave reminders, or temporarily disable a line.

# This whole line is a comment
name = "Alice"   # comment at end of line

# print("this line is turned off")
print(name)      # only this runs
🧠 Think of sticky notes on a recipe. The note doesn't change the recipe — it's just a reminder for the cook. A comment doesn't change your program — it's a reminder for you (or whoever reads your code next).
💡 Good habit: add a comment at the top of every file saying what the program does.
