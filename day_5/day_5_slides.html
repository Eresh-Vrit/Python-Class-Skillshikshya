Why Do We Need Loops? 🤔

Without a loop, repeating an action means copy-pasting the same code over and over. That's tedious, error-prone, and impossible to scale.

❌ Without a loop (5 friends)

print("Hello, Alice!")
print("Hello, Bob!")
print("Hello, Charlie!")
print("Hello, Diana!")
print("Hello, Eve!")
→ 100 friends = 100 lines? 😱
→

✅ With a loop (any number of friends)

friends = ["Alice","Bob","Charlie",
           "Diana","Eve", ...100 more]

for name in friends:
    print(f"Hello, {name}!")

→ Works for 5, 500, or 5 million friends!
🧠 A loop is Python's way of saying: "do this for every item" or "keep doing this until I tell you to stop".

The for Loop
Loop over items in a list

The for Loop — Building Blocks

A for loop takes each item from a list (or any sequence), puts it in a variable, and runs the indented block. Then it moves to the next item.

friends = ["Alice", "Bob", "Charlie"]
#          ↑ the list Python will loop over

for name in friends:
#    ↑         ↑
# loop var    the list
    print(f"Hello, {name}!")
# ↑ indented — runs every round
⚠️ The colon : after for ... in ...: is required. The body MUST be indented 4 spaces!

for Loop in Action 🔥

LOOP BODY CAN HAVE MANY LINES
fruits = ["apple", "banana", "mango"]

for fruit in fruits:
    upper  = fruit.upper()     # ← inside
    length = len(fruit)        # ← inside
    print(f"{upper} — {length} letters")

print("Done!")  # ← NOT indented, runs once
Everything at the same indent level repeats every round!
LOOP + IF — THE POWER COMBO
scores = [85, 42, 91, 38, 77, 55]

for score in scores:
    if score >= 60:
        print(f"{score} → PASS ✅")
    else:
        print(f"{score} → FAIL ❌")

# 85 → PASS ✅
# 42 → FAIL ❌  ... etc.
💡 Combining a loop with an if is the most common pattern in all of Python!

range()
Loop a fixed number of times

range() — Count for Me, Python!

When you don't have a list but need to repeat something N times, use range() to generate numbers automatically.

# range(5) generates: 0, 1, 2, 3, 4
for i in range(5):
    print(f"Round {i}")
# Prints: Round 0, Round 1, Round 2, Round 3, Round 4

# range(1, 6) generates: 1, 2, 3, 4, 5
for i in range(1, 6):
    print(f"5 × {i} = {5 * i}")
🔑 range(n) starts at 0 and stops before n. The stop number is never included!

Accumulator
The most useful loop pattern

The Accumulator Pattern

Start with an empty "bucket" before the loop, then fill it up a little each round. This pattern solves almost every loop problem you'll meet!

# Pattern: create → loop → update
total = 0               # 1. Create the bucket

for price in prices:
    total += price    # 2. Add a little each round

print(total)          # 3. Use the final result
🔑 The bucket can be a number (0), a string (""), or even a list ([]). Start empty, build up!

Accumulator in Action 🪣

SUM & COUNT
scores = [85, 42, 91, 38, 77]

total = 0
count = 0

for s in scores:
    total += s
    if s >= 60:
        count += 1

print(f"Sum: {total}, Passing: {count}")
You can have MULTIPLE buckets tracking different things!
FIND THE MAXIMUM
numbers = [34, 78, 12, 99, 56]

biggest = numbers[0]   # start with first item

for n in numbers:
    if n > biggest:
        biggest = n     # new champion!

print(f"Biggest: {biggest}")
🧠 This is exactly how Python's built-in max() works under the hood!

while Loop
Loop until something changes

The while Loop — Keep Going Until...

A for loop runs over a known list. A while loop runs as long as a condition stays True — perfect when you don't know how many times you need to repeat.

# Anatomy of a while loop
countdown = 5

while countdown > 0:
    print(f"T minus {countdown}...")
    countdown -= 1   # CRITICAL: change the variable!

print("Liftoff! 🚀")
⚠️ If you forget to change the variable inside the loop, it runs forever! Press Ctrl+C to stop a runaway loop.

while in Action 🔁

Password retry

secret = "python"
guess = input("Password: ")

while guess != secret:
    print("Wrong! Try again.")
    guess = input("Password: ")

print("Access granted! 🔓")
💡 You don't know how many attempts the user needs — while is perfect!

Flag variable pattern

running = True

while running:
    entry = input("Number (or 'quit'): ")

    if entry == "quit":
        running = False
    else:
        n = float(entry)
        print(f"Square: {n}² = {n}")

print("Bye!")
✨ A boolean flag makes the loop's purpose crystal clear!

break & continue
Control your loops

break vs continue

🛑 break — EXIT the loop
for fruit in fruits:
    if fruit == "mango":
        break       # STOP everything
    print(fruit)
Jumps OUT immediately. The loop ends.
⏭️ continue — SKIP this round
for num in numbers:
    if num < 0:
        continue  # skip to NEXT
    print(num)
Skips the rest of THIS round. Loop keeps going.
🧠 break = "I'm done."    continue = "Not this one. Next!"

Nested Loops — Loop Inside a Loop 🪆

3 DAYS, 2 MEALS EACH
for day in range(1, 4):        # outer
    print(f"Day {day}")
    for meal in range(1, 3):   # inner
        print(f"  Meal {meal}")

# Day 1
#   Meal 1
#   Meal 2
# Day 2 ... and so on
For EVERY day, the inner loop runs all the way through.
STAR TRIANGLE
for row in range(1, 5):
    for star in range(row):
        print("*", end=" ")
    print()

# *
# * *
# * * *
# * * * *
🧠 Row 1 gets 1 star, row 2 gets 2 stars — the inner loop depends on the outer number!

Common Mistakes Today ⚠️

❌ Forgetting to update the while variable
while countdown > 0:
  print(countdown)
  # countdown never changes → forever!
while countdown > 0:
  print(countdown)
  countdown -= 1 ✅
❌ Using = instead of += in an accumulator
total = total + price
# Works but verbose
total += price ✅
# Cleaner and more Pythonic
